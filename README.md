#java-college-management-system

A desktop-based application designed to help educational institutions manage student records, courses, and administrative operations efficiently. Built using Java Swing for the graphical user interface and MySQL for database storage.

---

## 🚀 Features

* **Student Management:** Add, update, view, and delete student records.
* **User-Friendly GUI:** Simple desktop interface built with Java Swing.
* **Database Integration:** Persistent and secure data storage using JDBC and MySQL.

---

## 🛠️ Tech Stack

* **Programming Language:** Java (JDK 8 or higher)
* **User Interface:** Java Swing / AWT
* **Database:** MySQL
* **Database Driver:** JDBC (MySQL Connector/J)
* **IDE Used:** Eclipse IDE
